03 Projects

Things I've built, with honest status.

Engel

iOS journaling app / 2026 — Present / In build

A local-first iOS journaling app structured as a digital examen — 30-second voice memos sorted into binary positive / negative globes, with silent AI auto-tagging and pattern surfacing at write time. Local persistence runs on SwiftData alongside a FastAPI service for Whisper transcription and tagging; I designed the REST contracts between the Swift client and the Python service, and shipped the full UI — drag-to-sort, voice capture, animated globe light fields, and an inline consequence-surfacing chat over your own entries.

  • SwiftUI
  • SwiftData
  • FastAPI
  • Whisper
  • Claude Code

Quarry

AI research platform / 2025 — Present / Shipped

A full-stack research platform built from scratch: a React 18 + Material UI front end over a FastAPI back end via REST and SSE streaming, locked by a 169-test integration suite and deployed to Railway with continuous deployment. A four-stage pipeline — claim extraction, reconciliation, brief generation, contradiction detection — runs across OpenAI and Gemini through OpenRouter. It also ships a Finance Terminal with live watchlists and 1D–5Y charts, QFL (a custom query language), and citations in APA, MLA, Chicago, and BibTeX.
